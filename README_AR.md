# Study Timer Floating

تطبيق Android أصلي يعرض عدادًا عائمًا يتكرر كل 10 ثوانٍ.

## التشغيل
1. افتح التطبيق.
2. اضغط Start floating timer.
3. اسمح للتطبيق بالظهور فوق التطبيقات الأخرى.
4. اسمح بالإشعارات إذا طلب Android ذلك.
5. سيظهر العداد أعلى يمين الشاشة ويمكن سحبه لأي مكان.
6. زر Ⅱ للإيقاف المؤقت، ▶ للاستكمال، و × للإيقاف النهائي.

الخدمة تعمل كـ Foreground Service أثناء تشغيلها. إيقاف التطبيق إجباريًا أو قيود البطارية الشديدة لدى بعض الشركات قد توقفها. عند إطفاء الشاشة لن تكون النافذة مرئية، لكن العداد يعاود حساب الوقت عند إضاءة الشاشة.
